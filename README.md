# Rock Paper Scissors

A simple Rock Paper Scissors game made with HTML, CSS and JavaScript.

Choose Rock, Paper, or Scissors and play against the computer. The score updates after every round.

### Live Demo

[Play the game](https://niket-jain2005.github.io/Rock-Pape-Scissors/)

### Built With

* HTML
* CSS
* JavaScript

### Features

* Player vs Computer
* Random computer choice
* Score tracking
* Win, lose and draw messages
* Simple interactive UI
